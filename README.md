## 🛵 Proyecto actual: Rapxi

App de mototaxi hecha en **Flutter** para conectar pasajeros y conductores en Quibdó.

- 📍 Mapa con la ruta por las calles (OpenStreetMap + OSRM)
- 💬 Chat entre pasajero y conductor
- 🤝 Contraoferta de precio y calificación del viaje
- 🧑‍💼 Panel de administrador para aprobar conductores
- 🔥 Base de datos y autenticación con Firebase
